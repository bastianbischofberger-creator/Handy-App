Wer arbeitet auf diesem Gerät?

Dein Name wird bei jedem Eintrag gespeichert, damit man sieht, wer was geschrieben hat. Er bleibt auf diesem Gerät gespeichert.

Diktat-Einstellungen

Tipp: Hochdeutsch, ruhig und in kurzen Sätzen sprechen. Mundart wird nur teilweise erkannt. Probier aus, ob «Schweiz» oder «Deutschland» auf deinem Gerät besser klappt.

Pro Zeile: erkannt = richtig, z. B. te el ef = TLF. Mehrere Schreibweisen mit «|» trennen: reco | recco = Reko. Gross-/Kleinschreibung links spielt keine Rolle.

Gesprochene Satzzeichen: «Punkt», «Komma», «Doppelpunkt», «Fragezeichen», «Ausrufezeichen», «Bindestrich», «neue Zeile».
